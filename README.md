# RideCompare.ai

Smart ride comparison demo for Anand routes.

## Features
- Compare Uber Go, Rapido Bike, Auto and CabGo Mini demo fares
- Distance-based demo pricing from ₹10 to ₹90
- Interactive OpenStreetMap/Leaflet route map
- Cheapest, fastest and shortest sorting
- Anand route locations
- Public compare API endpoint

## Run locally
Serve the project with any static HTTP server. The frontend is in `public/`.

Example:
```bash
python -m http.server 8080 --directory public
```

Provider prices are illustrative demo estimates, not live provider quotes.
